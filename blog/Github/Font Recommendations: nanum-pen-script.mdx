## 介绍

[Nanum Pen Script](https://fonts.google.com/specimen/Nanum+Pen+Script) 是 Naver（当时还叫 NHN）"한글한글아름답게"（让韩文更美）字体计划里的一款，找的是韩国字体公司 [Sandoll Communications](https://www.sandoll.co.kr) 定制（Sandoll 也做过 Malgun Gothic、Apple SD Gothic Neo 这些常见韩文字体），2010 年发布，2012 年 5 月收进 Google Fonts。源码开源在 [naver/nanumfont](https://github.com/naver/nanumfont) 仓库，SIL 开源字体许可证（OFL 1.1），免费商用不用署名。

钢笔手写风格，笔画粗细比较均匀、字形干净，比同系列的 Nanum Brush Script（毛笔风格）克制很多，适合需要一点手写感又不想太张扬的场景。支持韩文和基本拉丁字母。

## 字重和获取方式

只有一个 Regular（400）字重，没有其他字重或斜体。去 [Google Fonts 页面](https://fonts.google.com/specimen/Nanum+Pen+Script)下载，或者网页里直接引入：

```
https://fonts.googleapis.com/css2?family=Nanum+Pen+Script&display=swap
```

> 用 `next/font/google` 之类的方案接进项目的话，CSS 变量名按自己项目的命名习惯来就行，比如 `--font-nanum-pen`。

## 在 macOS 上安装

下载下来的 ttf 文件双击，字体册里点安装就行。

## 相关字体

同属 Nanum 系列的还有 [Nanum Brush Script](https://fonts.google.com/specimen/Nanum+Brush+Script)，毛笔字风格，笔画粗细变化更大、更随性，跟 Pen Script 的克制正好是两个方向。另一款常被拿来对比的韩文手写体是 [Gaegu](https://fonts.google.com/specimen/Gaegu)，同样是 Google Fonts 上的开源字体，带 Light / Regular / Bold 三个字重，风格更偏可爱、孩子气一些。

## 总结

Nanum Pen Script 是那种拿来就能用的开源字体，Google Fonts 直接引入或者下载 ttf 装到系统都行，唯一要注意的是只有一个字重，想要更粗或者更细的笔画得换字体。
