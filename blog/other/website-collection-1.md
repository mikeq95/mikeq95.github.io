## 1. macOS Icons

[macosicons.com](https://macosicons.com) 收集了大量自定义 macOS App 图标，免费下载替换 Dock 里的默认图标，用来美化系统。

## 2. Emojipedia · Apple

[emojipedia.org/apple](https://emojipedia.org/apple) 专门展示苹果系统的 emoji 设计，能看到同一个 emoji 在不同 iOS 版本下的样子变化。

## 3. OSS Insight

[ossinsight.io](https://ossinsight.io) 由 PingCAP 打造，用可视化图表展示 GitHub 开源项目的数据洞察，比如 Star 增长趋势、语言排行榜、贡献者活跃度等。

## 4. Vocatype

[vocatype.app](https://vocatype.app) 是一个免费的触控打字练习网站，支持英文、泰文、韩文键盘，边打边练十指输入，顺带也能练拼写。

## 5. Claude’s Sticker

[stickermule.com/claudecode](https://www.stickermule.com/claudecode) 是 Claude Code 的周边贴纸商店，款式不少，页面本身也做得挺好看，先 mark 一下。

## 6. App Store Price

[appstoreprice.org](https://appstoreprice.org) 可以实时对比不同地区 App Store 里同一款 App 的价格，还带汇率换算，买付费 App 或内购前先看一眼挺有用。

## 7. Develop in Swift Tutorials

[developer.apple.com/tutorials/develop-in-swift](https://developer.apple.com/tutorials/develop-in-swift/welcome-to-develop-in-swift-tutorials) 是苹果官方的 Swift 入门教程，从零开始用 SwiftUI 做 App，适合想系统学 Swift 的人。

## 8. IP Check

[ipcheck.ing](https://ipcheck.ing/#/) 用来查看当前 IP 相关信息，排查网络、代理或节点是否生效时挺方便。

## 9. KuKuTool 去水印

[dy.kukutool.com](https://dy.kukutool.com/zh-Hans-SG) 在线解析短视频和图片链接，去掉平台水印后再下载，免登录、不限次数，支持抖音、小红书、B 站等很多平台。

## 10. uiGradients

[uigradients.com](https://uigradients.com/#Kyoto) 收集了一批现成的漂亮渐变色，点开就能复制 CSS，做网页背景或 UI 配色时直接用。
